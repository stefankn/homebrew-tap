# homebrew-tap

Homebrew tap for my tools.

| Name | Install | Description |
|---|---|---|
| [runway](https://github.com/stefankn/runway) | `brew install stefankn/tap/runway` | Build, run and stream logs for Xcode apps from the terminal |
| [purrview-cli](https://github.com/stefankn/purrview-cli) | `brew install stefankn/tap/purrview-cli` | Command line launcher for the Purrview markdown viewer. Installs the `purrview` command; the Purrview app must already be installed. |

Homebrew asks you to trust a third-party tap on first install:

```sh
brew trust stefankn/tap
```

`Casks/runway.rb` is generated by runway's release workflow, so don't edit it by hand.
